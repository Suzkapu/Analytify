Privacy Policy & Data Handling (GDPR & Spotify Compliance)

  • Local Data: By default, data retrieved from the Spotify API is stored locally in your browser to authenticate your session and render metrics. Personal Spotify app users can use Playlists, Stats, History, and analysis without creating a cloud identity.
  • Personal Spotify Apps: You may provide your public Spotify Client ID and authorize with PKCE. Analytify never requests a Spotify Client Secret, email address, phone number, password, or recovery identity. The Spotify ID, display name, and profile image returned by Spotify are used to identify the local profile.
  • Cloud Features (Optional): If you explicitly enable Cloud Backup or a server-backed Workspace feature, your Spotify ID, display name, profile image, selected listening data, and stats snapshots are stored in Supabase. A Spotify refresh token is encrypted for scheduled jobs. Personal-app users receive an anonymous, browser-bound Supabase identity with no email or phone; it cannot be recovered after browser data is cleared.
  • Push Notifications (Optional): If you enable a notification category, Analytify stores the Web Push endpoint and encryption keys created by that PWA device. Song League uses them only for the categories you select, such as announcing that a Friday pick window opened or that another member added a song. You can disable each category at any time from Song League or Data & account → Notifications; clearing cloud data deletes every registered device endpoint.
  • Right to Erasure (GDPR Article 17): You can completely erase all your data at any time:
    • Cloud Data: Click the profile icon, select Clear Data, and choose Delete Cloud Backup to permanently wipe all synced history, snapshots, and caches from our database.
    • Local Cache & Logout: Select Clear Local Cache & Logout to wipe browser data and terminate the session. For an anonymous cloud identity this also permanently deletes the identity and its linked server data because no recovery identity exists.
    • Revoke App Access: Click the "Revoke App Access" link in the profile settings dropdown to manage permissions directly on the Spotify Apps dashboard.
