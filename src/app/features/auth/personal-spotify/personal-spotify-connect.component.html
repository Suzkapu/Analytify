Personal Spotify app

Connect without an Analytify account

Sign in with your own Spotify app. Your verified Spotify ID restores the same Analytify workspace on your other devices. Analytify does not ask for an email, phone number, password, or Client Secret.

Before Spotify opens: Analytify requests your profile, saved songs, and playlists. Playlist write access is requested only when you choose to create or update a playlist copy.

  1. 1

    Create or open your Spotify app

    Use Spotify's Developer Dashboard. When creating the app, select Web API. Spotify currently requires the app owner to have Premium.

    Open Spotify Developer Dashboard
  2. 2

    Add this Redirect URI

    Open Settings, add this under Redirect URIs, and save. It must match exactly.

    {{ callbackUri }}
  3. 3

    Enter your Spotify user ID

    This is checked against Spotify after login. Typing an ID alone can never open or change its workspace.

  4. 4

    Use the saved app or paste a new Client ID

    Leave this empty to use the app saved for your verified Spotify ID. Paste a new 32-character Client ID after replacing a deleted app. It is saved only after Spotify verifies the same account. Never paste your Client Secret.
