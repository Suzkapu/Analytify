# Automatic Updates interaction contract

Canonical Figma: [desktop list](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=44-1757), [mobile list](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=7-312), [desktop editor](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=27-1260), [mobile editor](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=35-1931), [Every](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=988-32264), [Unit](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=988-32281), [feedback family](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=988-32207), [availability summaries](https://www.figma.com/design/5v8ckmlbfhMDWwP5sTdSXd?node-id=991-32254).

The protected Settings Updates route reads `get_my_sync_task_status`. Each real task row supplies its interval, minimum, optional/required/effective state and policy availability. Empty results do not produce invented schedules. Required tasks and unavailable policies have no edit link. Inactive feature-owned tasks are Disabled; noneditable does not imply Required. Titles and icons map the six known task keys; an unknown noneditable task receives neutral identity without a substituted icon.

An editable summary opens the full-page task editor. The native switch, Every popup Apply and Unit buttons modify only a local draft. Every uses a free numeric input, current unit minimum (rounded upward) and a seven-day maximum. Unit selection retains the numeric value and changes the unit; validation applies before saving. No preset demonstration values are shipped as product choices. Cancel, Escape and backdrop dismissal discard popup input; Cancel remains the final action. The shared accessible-dialog directive isolates the background, traps focus, initially focuses the input/first unit and restores the invoking field.

Save validates whole integers, units, authoritative policy minimum and maximum, then calls `update_my_sync_schedule_preference` with the selected task and cloned draft. All editor controls are disabled while the write/readback is pending; duplicate Save and refresh are blocked. A failed write retains the draft for retry. Success is announced only after a current-context authoritative readback. Leaving through Back or other navigation discards unsaved changes. Changing the route ID clears the preceding task's draft, result/error/success and popup state, even when Angular reuses the component.

Requests capture Spotify/cloud identity, request revision and session-generation signal. Late successful or rejected responses never publish into another actor, task or destroyed editor; client initialization is checked before dispatch. A request already dispatched may have reached the server; abort/result guards do not establish rollback of its server-side effect. The server remains authoritative for permissions and task minima. No worker/database code or shared deployment is changed.

Loading, empty, retry, cached-refresh, saving, validation, locked/unavailable and saved feedback use the canonical shared inline status. Returning to the window triggers refresh while cached rows/drafts remain visible. A refreshed required/unavailable policy removes write controls and closes its popup; it is not revived when a later refresh unlocks the task. The existing `/new` service-worker/release boundaries are unchanged. Browser fixtures block all real remote traffic and never run workers or deliver notifications.

Visual evidence consists of reviewed rendered panels and numeric geometry at multiple widths/heights in Chromium, Firefox and headless WebKit; screenshot captures are candidates, not approved full-page golden regressions. Shared shell/sidebar/footer gaps remain outside this slice and prevent a full-page parity claim. Static Switch states reuse exact local SVGs; motion parity is unverified where Figma motion metadata is unavailable. Sidebar animation remains provisional per the user.
