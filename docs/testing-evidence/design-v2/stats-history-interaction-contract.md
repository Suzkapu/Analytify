## Data and recovery

- Rank1 is at the top; scale bounds are100 songs,50 artists and15 genres. Retain daily snapshot order and existing date/identity merging rules. Cloud duplicates choose the best rank per date; an already-loaded local daily snapshot takes precedence over conflicting cloud values. Current local data remains authoritative for today. Cloud requests remain owner-, period- and item-scoped.
- An empty successful result differs from a failed request. `SupabaseService.loadStatsItemTrendResult` returns `ready` with dated points or `unavailable` with no failed data. Malformed present cloud ranks/calendar dates are unavailable rather than invented positions, poisoned same-day deduplication or successful empty history. Valid positive integer serializers and leap days remain accepted. The legacy array API retains its empty fallback. The v2 controller now consumes the explicit result; unavailable results enter the failure path while the legacy controller retains its array fallback.
- Show no invented curve for zero/one positions. One position is readable as its actual date/rank, with ISO datetime and an accessible year on its time element. A successful empty history explains daily snapshots and changing the ranking date/period.
- Cloud failure with local positions preserves those positions and offers Retry. Zero positions uses Unavailable; one uses PartialSingle; two or more use Partial. A retry retains available local data, disables duplicate requests and keeps Close available. Failures never appear as successful empty history.
- Closing, changing the item/period or destroying the controller invalidates pending responses. Old successes and failures must not replace newer data, clear newer busy state or reopen the popup. Existing sequence-ownership tests cover controller replacement/close/destruction; v2-specific tests cover failures, local preservation, duplicate retry, stale results, closed retry versus replacement retry, period changes and routing from private to shared owner.

## Keyboard and responsive behavior

Inspect every position with Left/Right/Home/End and announce its actual date/rank. Sample visible axis labels in dense histories without removing positions from inspection or the accessible table. Table disclosure keeps item/category/period and has semantic date/position headers.

Close is last in reading/tab order and initially focused; Escape/backdrop close and return focus to the trigger. On short windows only the dialog body scrolls, keeping Close visible. Use16px outer gutters,32px desktop/24px mobile inner padding,44px actions, shared Outfit text styles, semantic colors/radii and the existing12px backdrop blur. Tall windows center the complete composition. Reduced motion removes nonessential entrance/inspection/loading movement; busy status remains perceivable.
