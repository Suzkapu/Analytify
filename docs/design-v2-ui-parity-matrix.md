# Design v2 UI-surface parity matrix

This is the release inventory for the canonical Design v2 presentation. A row applies to every surface named in its **Included surfaces** cell; grouping does not waive any surface. `Complete` means the canonical path has intentional states and evidence. Any blank, `Missing`, `Blocked`, or remaining legacy adapter fails the release gate.

Evidence codes: `U` unit, `B` browser/Playwright, `A` Axe, `K` keyboard/focus, `R` responsive/reflow, `P` performance/bundle. Shell modes are `app`, `focus`, and `public`. Layouts are the approved `form`, `default`, `dashboard`, `full`, and `reading` variants.

## Release rules

1. A migration that adds, removes, or changes a user-visible surface must update both tables and its evidence in the same change.
2. #163 samples nested, claim, callback, error, permission, destructive, and reduced-motion states from this matrix; a top-level route smoke test is insufficient.
3. Legacy presentation adapters are not permitted in the canonical route tree. `/new/*` remains only as a routing-layer redirect for old bookmarks and external links.
4. `app-ambient-background` may appear exactly once, in `DesignV2Shell`; feature-level renderers are a rollout blocker.
5. Canonical rollout requires every final verification status to remain `Complete`, all tests green, and every adapter entry to remain `No`.
