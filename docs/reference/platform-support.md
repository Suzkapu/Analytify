# Platform requirements

These are planned requirements and can still change.

## Android

- ARM.

## iOS

- ARM.
- Compatible with iOS design.

## Windows

- x86-64 and ARM; no 32-bit x86 support needed.
- Additional compatibility requirement: not finished yet.

## Linux

- x86-64 and ARM; no 32-bit x86 support needed.
- AppImage and Flatpak.

## macOS

- ARM.

## Website

- Hosted on a Linux server.
- Works in Chrome, Firefox, and Safari-based browsers.

## Server backend

- A separate server backend handles automatic calls. The remaining details are not finished yet.
