## Data and security

- Store app data locally by default. Optional sync and online features require the user to choose those services.
- Choose secure storage for server secrets and user tokens, including key rotation and recovery. Never put private keys in Git or client apps.
- Enforce access to private sharing, friends, Song League, and administration on the server and through Supabase policies where applicable.
